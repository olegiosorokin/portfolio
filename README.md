# Портфолио Олега Сорокина
**Версия:** 2.0.1

Динамическое портфолио с интерактивной лабораторией отображения контента. Проект демонстрирует не только готовые работы, но и архитектуру, организацию данных и управление интерфейсом.

---

## Об этом сайте

- **HTML:** 1 файл — базовая структура и точки монтирования
- **CSS:** 2 файла — `base.css` (типографика, сетка, переменные), `change.css` (темы, режимы, вариации отображения)
- **JS:** 4 файла — `main.js` (ядро), `templates.js` (шаблоны), `projects.js` (данные проектов), `about.js` (данные раздела)
- **Лаборатория:** 7 режимов отображения контента
- **Темы:** светлая и тёмная
- **Адаптивность:** планшеты — 4 режима, телефоны — 2 режима
- Динамическая смена режима отображения на мобильных через JS
